# Competition data boundary

The supplied PRC 2026 dataset is used only for participation in the Data Challenge. This includes local model training, validation, ranking predictions and required competition reproducibility. Data access does not authorise use of the dataset or a model trained on it in the proprietary RALE/PhoenixAI product.

Owner-supplied organizer clarification dated 7 September 2026 states that a future data-paper release is expected around April 2027. That would be a historical snapshot, not a continuous feed. The licence actually published at that time must be reviewed before any new use; a licence used for an earlier challenge is not permission for this dataset.

OpenSky operational/historical access for a commercial service is a separate request to OpenSky. EUROCONTROL does not supply that continuous service. No such access is enabled by this research repository.

The product's separate ADSB.lol observations, public forecasts and deterministic mission simulations do not import competition parquet files, fitted models or private competition records. Keep all training data, ranking data, bucket credentials and run artifacts outside Git. Publish only independently authored competition code and aggregate method/results documentation under GPL-3.0-only.

Provenance: owner-provided correspondence on 7 September 2026; original correspondence retained privately. Public competition conditions: https://prc-data-challenge-2026.netlify.app/eligibility.html and https://prc-data-challenge-2026.netlify.app/data.html.
